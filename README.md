# FixItNow Backend

Home services marketplace API — Node.js, Express, TypeScript, PostgreSQL, Prisma, JWT.

## Setup

```bash
npm install
cp .env.example .env
# fill in DATABASE_URL, JWT secrets, etc. in .env

npx prisma generate
npx prisma migrate dev --name init

npm run dev
```

Server runs on `http://localhost:5000` by default. Visit `/` for a health check.

## Folder structure

```
prisma/
  schema/         # multi-file Prisma schema (schema.prisma, enums.prisma, user.prisma, ...)
  migrations/      # generated by prisma migrate dev
src/
  config/          # environment config
  lib/prisma.ts    # Prisma client singleton
  middlewares/      # globalErrorHandler, notFound, auth (added later)
  modules/         # feature modules (auth, user, technician, booking, payment, review, admin ...)
  utils/           # catchAsync, sendResponse, ApiError
  app.ts
  server.ts
```
